**Forge** é um assistente de terminal inteligente projetado para desenvolvedores que buscam elegância e automação. Ele utiliza IA para forjar mensagens de commit perfeitas e documentações completas em segundos.

---

## ✨ Funcionalidades

- 🤖 **AI Commit:** Gera mensagens seguindo o padrão *Conventional Commits*.
- 📝 **Auto README:** Analisa seu código e cria documentação profissional.
- 🎨 **Modern TUI:** Interface rica com animações, cores e bordas.
- 🚀 **Turbo Workflow:** Faz o commit e o push em uma única interação.

## 🛠️ Instalação

```bash
# Clone o repositório
git clone [https://github.com/EmenegildoMarques0/forge.git](https://github.com/EmenegildoMarques0/forge.git)

# Entre na pasta
cd forge

# Instale globalmente
./scripts/install.sh
